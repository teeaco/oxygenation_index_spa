# Front RIP SPA (Лабораторная 5)

Базовое SPA на `React + TypeScript + Vite`.

## Что реализовано

- Дизайн и содержимое карточек перенесены из первой лабораторной (`RIP`, ветка `basic-disign`) в React-версию.
- Страницы:
  - `/` — стартовая
  - `/services` — список услуг
  - `/services/:id` — подробная карточка
  - `/oxygenation_request/:id` — страница последнего расчета (открывается из иконки корзины)
- Данные — только из mock-объектов (`src/data/*`), без бэкенда.
- Фильтры на странице услуг:
  - по названию/диапазону индекса (`query`)
  - по коэффициенту оксигенации (PaO2/FiO2)
- Дефолтное изображение для пустого `imageUrl`.
- Самописные `Breadcrumbs`.
- Без `Redux` и без `Context`.

## Быстрый старт

```bash
npm install
npm run dev
```

Открывай адрес из вывода Vite (обычно `http://localhost:5173`, либо следующий свободный порт).
