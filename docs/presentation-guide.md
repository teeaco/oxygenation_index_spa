# Порядок показа и пояснения

## 1. Демонстрация страниц

1. `Главная` (`/`) — стартовая страница.
2. `Список услуг` (`/services`) — карточки в стиле первой лабы, фильтры и иконка корзины.
3. `Подробнее` (`/services/:id`) — карточка выбранной степени.
4. `Заявка` (`/oxygenation_request/101`) — открывается по клику на иконку корзины.

## 2. Где показано изображение по-умолчанию

- Компонент карточки: `src/components/ServiceCard.tsx`
- Страница деталей: `src/pages/ServiceDetailsPage.tsx`
- Логика: `src={service.imageUrl || defaultImage}` и `onError={handleImageError}`

## 3. Компонент фильтрации и props

Компонент: `src/components/ServiceFilters.tsx`

Передаваемые props:

- `filters: ServiceFiltersState` — текущее состояние фильтров.
- `onChange(next)` — обновление фильтров из родительской страницы.

Родитель: `src/pages/ServicesPage.tsx`

- хранит состояние фильтров (`useState`)
- передаёт его в `ServiceFilters`
- применяет фильтры через `useMemo` к списку услуг

## 4. Используемые хуки

- `useState`
  - хранение списка услуг, состояния загрузки, фильтров и данных заявки.
- `useEffect`
  - загрузка списка услуг при первом рендере `/services`.
  - загрузка деталей при изменении `id` на `/services/:id`.
  - загрузка заявки и списка услуг на `/requests/:id`.
- `useMemo`
  - вычисление отфильтрованного списка.
  - вычисление строк таблицы для страницы заявки.
- `useParams`
  - чтение `id` из URL страниц деталей и заявки.

## 5. Краткие ответы на контрольные вопросы

- React: библиотека для описания UI через компоненты.
- Props и state: props приходят извне и только читаются, state хранится в компоненте и изменяется через setter.
- Компонент и элемент: компонент — функция/класс, элемент — объект описания UI, который возвращается компонентом.
- `useState` и `useEffect`: первый хранит состояние, второй выполняет побочные эффекты и работает с жизненным циклом.
- Жизненный цикл: mount, update, unmount; в функциональных компонентах он моделируется через хуки.
- Vite и Babel: Vite — dev-server и сборка, Babel — транспиляция современного JS/JSX.
