# Лабораторная 8 — порядок показа

## 1. GitHub Pages + PWA на телефоне

1. Открыть GitHub Pages URL на телефоне.
2. Установить приложение как PWA ("Добавить на главный экран").
3. Открыть установленное PWA.
4. На странице услуг ввести фильтр `PaO2/FiO2`, нажать `Найти`.
5. Перейти в `Подробнее` любой услуги и вернуться назад.
6. Показать, что значение фильтра сохранилось.

Что показать в DevTools:
- `Application -> Manifest` (без ошибок)
- `Application -> Service Workers` (active)

## 2. Адаптивность

1. Открыть режим адаптива в браузере (Device Toolbar).
2. Менять ширину экрана.
3. Показать:
- на десктопе карточки услуг в несколько колонок
- на планшете меньше колонок
- на телефоне одна колонка
- бургер-меню отображается только на мобильной ширине

Где в коде смотреть фиксированные значения:
- `src/index.css`:
  - `.cards-grid` — количество колонок
  - `.request-compact-main` — сетка карточек заявок
  - `.service-row-extended` — сетка строки услуг в заявке
  - `@media (max-width: 1400px | 1024px | 768px | 640px)` — брейкпоинты

## 3. Показ работы с backend на компьютере

1. Запустить backend.
2. Запустить фронтенд (`npm run dev`).
3. Открыть `https://<ваш-ip>:3000` (не localhost), чтобы показать работу по сети.
4. Показать в консоли dev-сервера Network URL и сравнить его с IP в конфиге.

Где IP в коде:
- `.env.tauri` (`VITE_BACKEND_URL`, `VITE_IMAGE_BACKEND_URL`)
- `src-tauri/tauri.conf.json` (`devUrl`, `csp`)

## 4. Short polling (обязательно показать в F12)

1. Авторизоваться модератором.
2. Открыть страницу заявок.
3. В F12 открыть `Network`.
4. Отфильтровать по `listRequests` / `oxygenation_request`.
5. Показать повторяющиеся запросы каждые ~5 сек.

Где это в коде:
- `src/pages/RequestsPage.tsx` — `setInterval(..., 5000)` в `useEffect`.

## 5. Tauri build (не dev)

1. Собрать приложение: `npm run tauri:build`.
2. Запустить собранный `.exe` из `src-tauri/target/release/bundle/...`.
3. Показать загрузку услуг с backend (по LAN IP, не localhost).
4. В БД изменить услугу, обновить Tauri-окно, показать изменение.

Важно:
- Для сборки нужен установленный Rust/Cargo.

## 6. HTTPS в локально развернутом фронтенде

1. Запустить `npm run dev`.
2. Открыть `https://localhost:3000` (или `https://<ip>:3000`).
3. Показать, что страница и Service Worker работают по HTTPS.

## 7. Wireshark / tcpdump (порт Tauri)

1. Открыть Wireshark.
2. Применить фильтр: `tcp.port == 8080` (порт backend).
3. Выполнить действие в Tauri (например, открыть список услуг).
4. В пакете найти `Src Port` — это исходящий порт Tauri-приложения.
5. Этот порт перенести в deployment диаграмму.
